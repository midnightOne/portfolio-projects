## What this is

A portfolio website that is itself the flagship portfolio piece: a production Next.js application whose embedded AI assistant demonstrates, live, current AI engineering — speech-to-speech agents, agent-driven UI, RAG/context engineering, and (planned) a hardened public MCP server.

## Stack

Next.js 15.4 (App Router, SSR) · React 19 · TypeScript · Prisma 6 + PostgreSQL + **pgvector** (HNSW) · Tailwind 4 + shadcn/ui · GSAP (+ Three.js wave hero) · Tiptap 3 · NextAuth · `@openai/agents` (Realtime, WebRTC) · `@elevenlabs/client` · deployed on **Vercel serverless** (durable state in Postgres; in-memory caches are per-instance memoization only).

## Architectural signatures (what to look at)

- **Client-direct voice with ephemeral tokens:** the server mints short-lived provider tokens with the system prompt and tool schema injected at mint; audio never proxies through our infrastructure. (`ai-assistant/design-voice-adapters.md`)
- **One tool chain, exposed twice:** `UnifiedToolRegistry` server tools execute in `BackendToolService`; the voice assistant and the (planned) MCP server share those implementations — no endpoint clones. (`ai-assistant/design-tools-and-context.md`)
- **Passive F-I-D context:** Frame/Index/Details state is pushed to the model (replace-don't-append) so it orients without tool calls — context engineering, demonstrated. 
- **Heading-bounded T0–T3 chunking with section-hash surgical regeneration** on pgvector/HNSW, generated by a resumable stage-based pipeline. (`semantic-content/HEADING_BOUNDED_CHUNKING.md`)
- **Cost defense as a chokepoint (planned):** one gateway wraps every cost-incurring route — kill switch, Turnstile-gated public sessions, hashed-IP rate limits, unified usage ledger, spend watchdog that fails closed. (`access-and-cost/design.md`)
- **Two voice families behind one interface (planned, D45):** native speech-to-speech (OpenAI Realtime, Gemini Live) next to a cascade (streaming STT → reasoning LLM → ElevenLabs TTS) that shares its brain with text chat — identical answers across modes, reliable classic-LLM tool calls, A/B-able live. (`ai-assistant/design-voice-adapters.md`)
- **Verification as definition-of-done (D46):** deterministic fakes behind the adapter seams, a seeded fixture with assertable semantic output, executable acceptance checks, an authorized `_debug` telemetry envelope, and periodic live-fire runs — so an agent session can prove a feature end-to-end before checking it off. (`verification/`, `CLAUDE.md`)
